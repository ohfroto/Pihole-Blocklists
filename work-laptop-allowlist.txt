! Title: Work laptop allowlist
! Purpose: exceptions on top of normal blocking for one device (a work laptop), subscribed in
!   Pi-hole as an "Allow" type list scoped to a single group so it has no effect on any other
!   device on the network -- that scoping lives in Pi-hole's own group/client config, not here.
! Format note: unlike a block-type list, Pi-hole only recognises the ABP *exception* syntax
!   (`@@||domain^`) for allow-type lists -- plain `||domain^` lines are silently ignored, and a
!   bare domain with no `@@||...^` wrapper only matches that exact host, not its subdomains.
!   Confirmed empirically against this Pi-hole instance before writing this file.
! Compiled: 2026-10-19
